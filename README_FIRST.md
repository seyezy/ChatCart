# ChatCart v1.0.0 — Start Here

ChatCart is a Flutter + Firebase + Laravel chat and marketplace source-code package prepared for CodeCanyon.

## Main folders
- `Flutter_App/` — Flutter app with development, staging and production flavors
- `Laravel_Backend/` — Laravel 13 API + admin dashboard + installer
- `Figma_Plugin/` — editable Figma UI generator
- `Documentation/` — setup, Firebase, flavors, Laravel and CodeCanyon deployment guides
- `Presentations/` — CodeCanyon sales graphics and brand assets
- `Demo/` — demo-account guidance
- `Checklists/` — buyer and author release checklists

Open `Documentation/index.html` first.
