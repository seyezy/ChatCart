# ChatCart Demo Credentials

No universal production password is embedded in the source. The buyer creates the first administrator using the Laravel installer.

For your own hosted CodeCanyon demo, create a restricted account such as:
- Email: `demo.admin@yourdomain.com`
- Password: choose a demo-only password and reset demo data automatically

Do not use demo credentials on a production installation.

Sample records are created by:
```bash
cd Laravel_Backend
php artisan db:seed
```
