Quick start

cd Laravel_Backend
composer install
cp .env.development.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve
cd Flutter_App
flutter pub get
flutter run --flavor development

Architecture

Flutter provides the mobile UI and flavor selection. Firebase provides user authentication, realtime chat, typing/presence, media and push infrastructure. Laravel + MySQL provides the REST API and authoritative business/admin data for products, KYC, orders, payments, reports, support, announcements, devices and RBAC.

Security

Flutter `.env` files contain public client configuration and are bundled into the app. Server secrets belong only in Laravel `.env` or protected server files. Never ship Firebase service-account JSON or payment secret keys in Flutter.
