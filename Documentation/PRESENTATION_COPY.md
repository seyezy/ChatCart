## Three environments, one clean workflow
Develop safely. Test confidently. Release cleanly. ChatCart includes dedicated **Development**, **Staging** and **Production** flavors with separate app IDs, Firebase configuration and API endpoints.

- Development — `com.chatcart.app.dev`
- Staging — `com.chatcart.app.stg`
- Production — `com.chatcart.app`

## Laravel-powered business backend
Run marketplace operations from a secure Laravel API and administration dashboard. Manage sellers, KYC, products, orders, transactions, commissions, refunds, reports, support, announcements, roles and permissions from one backend.

## Real-time communication meets commerce
Move naturally from product discovery to seller conversation and checkout. Firebase powers realtime messages, typing indicators, online presence, read receipts, media delivery and push notifications.

## Built for customization
Centralized themes, reusable Flutter components, editable Figma screens, environment configuration and structured Laravel modules make ChatCart a strong foundation for agencies, startups and marketplace products.
