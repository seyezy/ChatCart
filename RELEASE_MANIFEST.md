# ChatCart v1.0.0 Release Manifest

## Mobile
Flutter application with three environments:
- development — `com.chatcart.app.dev` — `.env.development`
- staging — `com.chatcart.app.stg` — `.env.staging`
- production — `com.chatcart.app` — `.env.production`

## Backend
Laravel 13 + PHP 8.3+ + MySQL REST API and admin backend. Firebase remains the realtime/auth/media/push layer.

## CodeCanyon
Includes buyer installation workflow, Laravel environment templates, Flutter flavor documentation, Firebase guide, deployment guide, sample data, Figma generator, sales landing page and presentation assets.
