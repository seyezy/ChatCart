# License & Secure Setup

The distributed item should follow the selected Envato/CodeCanyon license terms. No real Envato purchase code, Firebase service-account key, signing keystore, Laravel `.env`, database password or payment secret should be bundled in the public download.

The Laravel installer configures the buyer's environment after Composer dependencies are installed. If online purchase verification is added later, use Envato's then-current official API and document the network request clearly.
