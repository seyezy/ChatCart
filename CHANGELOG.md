# ChatCart Changelog

## v1.0.0 — Initial CodeCanyon Release
- Flutter Light/Dark chat + marketplace application
- Development, staging and production flavors
- Android package suffixes `.dev`, `.stg` and production with no suffix
- Flavor-specific `.env.development`, `.env.staging`, `.env.production`
- Firebase Authentication, Firestore chat, Storage, RTDB presence/typing and FCM
- Laravel 13 + MySQL REST API and administration backend
- User/message reports and abuse workflows
- Seller KYC
- Marketplace, checkout, orders, transactions, commissions and refunds foundation
- Support tickets, announcements and device registration/revocation
- Roles, permissions and audit-ready backend schema
- Buyer web installer
- Editable Figma plugin output
- CodeCanyon documentation and presentation materials
